## 🎯 Tipo de Dashboard y Objetivo

* **Tipo de Dashboard:** Dashboard Analítico e Interactivo.
* **Objetivo:** Analizar métricas comerciales, evaluar tendencias de ventas y facilitar la toma de decisiones estratégicas mediante visualizaciones dinámicas y filtros interactivos.

---

## 🛠️ Tecnologías y Herramientas Utilizadas

* **Power BI Desktop**: Diseño del informe, maquetación e interactividad visual.
* **Power Query**: Proceso de limpieza, transformación y preparación de datos (ETL).
* **DAX (Data Analysis Expressions)**: Creación de medidas personalizadas, KPIs y cálculos dinámicos.

---

## 📊 Contenido del Reporte

* **Métricas Principales (KPIs):** Indicadores clave de rendimiento.
* **Filtros e Interactividad:** Segmentación por año, modelo, categoría o región.
* **Modelado de Datos:** Estructura optimizada para consultas rápidas y análisis preciso.

## 🚀 Cómo Abrir y Usar este Proyecto

1. Clona o descarga este repositorio a tu equipo.
2. Asegúrate de tener instalado **Power BI Desktop**.
3. Abre el archivo **`Reporte Mercedes-Benz - Estudiante.pbix`**.
4. ¡Explora las diferentes páginas e interactúa con los filtros y gráficos!
